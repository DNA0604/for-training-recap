# Satu Pintu — versi uji coba

GOAL: Pengelola memahami bahwa banyak aktivitas pelatihan dapat dipantau dalam satu dashboard, dari akses sampai laporan.

OUTPUT: Hyperframes, 1920×1080, 30 fps. TIME: 45 detik = 1.350 frame.

LOOK: Latar #f0f3f8 dan putih; tinta #192e50; aksen cyan #08a9d7 untuk satu penekanan per adegan. Heading Nunito 800/900 pada 80–106 px, tracking -3 px; penjelas 32 px. Antarmuka tetap tangkapan aplikasi asli tanpa perubahan piksel. Font UI mengikuti sumber. Logo asli yang telah disediakan pemilik. Radius media 24–28 px; bayangan 0 24 60 px pada navy 12–15%.

MOTION: Kedatangan power4.out 18–30 frame; kamera power3.inOut 24–33 frame; keluar power3.in 12–15 frame. Cursor 21–24 frame dengan klik 4+5 frame. Tidak ada loop dekoratif. Teks diam setelah mendarat. Transisi: konsolidasi panel → wipe antarmuka → zoom → iris pada tombol → geser panel → dokumen muncul → wipe end card.
